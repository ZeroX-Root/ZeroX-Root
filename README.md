## Sobre mí

Soy **Alejandro Guarín**, Full Stack Developer y fundador de **LlanoWeb**, una empresa de desarrollo web y software con base en Villavicencio, Colombia.

Construyo sistemas administrativos, plataformas de gestión y aplicaciones móviles nativas, combinando backend robusto, interfaces claras y arquitecturas mantenibles. Mi stack principal es **Laravel + Filament** para el backend y paneles administrativos, **Vue** para interfaces web, y **Flutter + Dart** para aplicaciones móviles multiplataforma.

Me interesa el software que resuelve problemas reales: sistemas de gestión empresarial, ERPs a medida, POS, y herramientas que automatizan procesos operativos.
